# Tic-Tac-Toe-War-of-the-Kingdoms
Tic-Tac-Toe: War of the Kingdoms is a medieval-themed twist on the classic Tic-Tac-Toe game. Two kingdoms clash in a strategic battle where every move matters. Featuring immersive fantasy visuals, interactive pieces, and a handcrafted game board, this project brings a legendary war to the classic 3×3 grid.
